🚀 Excited to share my latest low-level engineering project: ZVM - A Custom 8-Bit Virtual Machine Emulator!

Written completely from scratch in C, this project dives deep into Computer Architecture and Systems Programming. I designed a modular Instruction Set Architecture (ISA) and implemented a robust runtime environment that emulates how a real CPU operates.

💡 Key Architectural Highlights:

• Custom Register-Based CPU: Emulates 4 General-Purpose Registers (R0-R3), alongside dedicated IP, IR, and SP pointers.
• Advanced ISA Expansion: Successfully implemented and optimized a full suite of 10 Bitwise Operations (AND, OR, XOR, NOT, SHL, SHR, NAND, NOR, XNOR, ROL) handling logic directly at the bit level.
• Hardware-Level Exception Handling: Built an internal error-trapping loop (Fetch-Decode-Execute) to safe-guard against memory corruption, invalid registers, or stack overflows.
• Segmented Memory Layout: Features explicit definitions for isolated Data, Stack, and Code segments.
